Imagery Field v0.7.0: engineering preview

A self-contained, offline visual scene editor. This is an engineering preview, not a medical tool, treatment, diagnostic test, or validated way to develop mental imagery. Engineering bounds and successful software checks do not guarantee sensory safety.

Downloads
- Imagery-Field-portable.zip: recommended. Extract the entire ZIP, read START-HERE.txt and open Imagery-Field.html in a modern desktop browser. Includes the short guide, five current synthetic examples, two preserved legacy migration examples, MIT LICENSE, metadata and internal checksums.

- SHA256SUMS.txt and release-metadata.json: byte checks and exact source/evidence identifiers. Checksums detect changed bytes, not authenticity or software safety.

Highlights
- Static Live preview appears on first load, and valid item/background edits update it immediately. Startup never starts a timer or pulse.
- Background defaults to HSL 4 degrees, 60% saturation, 4% lightness. Background saturation supports 0-100%.
- Editable numeric slider values and fine-step minus/plus buttons.
- Independently colored outlines and shadows.
- Steady (no pulse), optional bounded opacity pulse, per-item start/fade/hold timing, overlap and finite automatic completion. Item playback is explicitly started and runs once.
- Separate one-pass snapshot-sequence playback. It does not run item animation inside snapshots.
- Revised responsive spacing, canonical user guide, troubleshooting, contribution/support/privacy guidance and synthetic examples.

Use and save
No installation, account, Node.js, Git, web server or runtime network connection is needed to use the app. Use Hide or Escape to conceal the display. Hidden/imported scenes require an explicit reveal. Apply accepts in-page edits; it does not save a file. Download and verify your scene/sequence before closing, because there is no durable autosave.

Known limits
Evidence covers automated Linux Chrome, including phone-sized touch emulation, not physical mobile devices or universal browser support. Ordinary native file-opening/download dialogs, Windows/macOS, Safari/Firefox, actual OS/browser zoom, comprehensive accessibility and human/clinical acceptance remain unverified. Reduced-motion preferences restrict timed playback. No hosted website is included in this Release.
