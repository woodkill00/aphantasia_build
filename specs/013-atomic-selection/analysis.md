## Concrete risks and conservative resolutions

1. **A rounded coordinate can be invalid when its original is valid.** The canonical validator preserves tolerated near-hundredth values. The outlined size-1 dot at X `2.80000000001` is valid while 2.8 violates its inset. Interval-only clamping forces an unintended inward movement; the opposite-bound fixture has no ordinary common lattice delta. Zero is a separate feasible unchanged-payload branch, not an expanded inset. Test exact zero, subquantum and outward pointer requests, snap-grid eligibility and infeasible exact nonzero rejection, including Y mirrors.
2. **Literal floating offset equality is the wrong invariant.** Accepted X `[41.23000000001, 48.34000000003]` has raw subtraction `7.110000000020001` but lattice difference 711. The planner preserves the latter on real changed-axis edits and exact raw numbers everywhere else. No-op detection precedes assignment. Test untouched orthogonal axes, unchanged individual targets within a mutating alignment, copies, reorders, cancellation and snapshot history.
3. **Generic cancellation can erase the user's error.** Baseline cancellation refreshes selected fields and precision overrides. Cancel-before-read loses freshly authored invalid text; replaying every DOM field can reintroduce provisional positions. Separate canonical rollback from field refresh and maintain a bounded authored-input channel. Exercise invalid global fields for multiple selection, singleton fields for one item, multiple simultaneous errors and stale pointerup. Hide must conceal without erasing correction state.
4. **Eager ordinary edit history clearing breaks recovery.** An invalid input event is not an accepted document mutation, and same-value correction must not consume an earlier arrangement stream. Clear only after successful staging of a genuinely different ordinary edit. Undo/Redo is rejected while raw input is invalid, without replacing it. Test the actual ordinary handler before any arrangement button is pressed.
5. **A controller stage is not always a completed command.** Pointermove is provisional. Any pre-final stage/render/UI failure restores the gesture origin and both completed stacks. Only final successful publication commits document/selection/history; a subsequent paint failure retains that complete hidden transaction. Inject preview stage, preview paint, final stage and post-final paint separately, and ensure success text cannot overwrite the failure/recovery message.
6. **Gesture revisions can self-cancel or miss recycled identity.** Advancing external revision for every provisional event breaks the second move; using generation alone lets an old callback target a reused ID after history eviction. Owner-token provisional writes plus distinct generation/external revision solve both. Require at least three owned moves, independent edit cancellation and same-generation reuse tests.
7. **Locks cannot be only record equality.** Selected locked endpoints reject even if geometrically unchanged. Reordering can preserve every record while moving locked targets, so history needs immutable targeted-ID policy in addition to full-record guards. Duplicate is deliberately different: originals are unchanged and new copies unlocked, but a newly locked copy prevents Undo removal. Preserve both stacks and selection on rejection.
8. **Naive alignment drifts on rotated shapes.** The source-grounded triangle fixture keeps moving by 0.01 on repeat if it always retargets rounded union edges. Recognize requested edge/midpoint spread ≤0.01+EPS first. Only newly computed mutation requires ≤0.005+EPS original-target error. Enforcing that narrower criterion on the already-satisfied branch wrongly rejects a valid spread of 0.009. Test all six modes and exact 100-repeat serialization, not visual similarity.
9. **Center and distribution are quantized, not exact geometry.** Multi-center uses a single delta per unsatisfied axis and preserves satisfied axes. Distribution recognizes ≥−EPS gaps with spread ≤0.02+EPS before recomputation. It preserves the original outer span within endpoint precision, not necessarily the original sorted endpoint items. New overlap or inset violation rejects; no repair can consume tolerance. Test unequal/nested shapes, tolerated endpoints, rotated endpoint rounding and both sides of comparison thresholds.
10. **Authored shape names are not geometry variants.** Authored dot/circle records may return polygon geometry. Dispatching by source shape invents a missing radius and corrupts bounds. Use returned kind, shared transformed points and exactly one body/contour/outline expansion; exclude shadows. Validate finite derived rectangle/scale/bounds, not merely finite input dimensions.
11. **A missing canvas must not disable data editing.** Geometry is required only for pointer mapping, edge/midpoint alignment, equal gaps and multi-center. Exact normalized translation, singleton position-centering, structural edits and snapshot history work without it. Test valid data commands alongside zero/missing/nonfinite/extreme viewport rejection and canvas failure. Never guess geometry or hide downloads/Hide behind a paint error.
12. **The native select can lie about select-only.** Showing primary as the current single-item select value in multiple selection means choosing it may fire no native change. Use a neutral empty-valued option; test trusted native selection of the already-primary ID. Timeline membership and individual property meaning are distinct. Disabled fields cannot be a hidden primary-edit route.
13. **Twelve accessible rows can still be unreachable.** A second nested scroller, clipped focus row or long primary/status text can obstruct the existing inspector aperture or move the captured canvas. Preserve keyed controls, 44-pixel targets and one established scroll surface. Inspect all longest labels, focus, corner/center hit targets and Hide at desktop/narrow/short sizes; source layout calculations alone do not pass.
14. **Layer changes do change canonical bytes.** Stable item records are not stable array order. Reorder must invalidate real edit provenance and be undoable, while selection-only changes must not. The spec explicitly corrects the historical proposal without rewriting its earlier acceptance history.
15. **History can grow or be consumed before a failed stage.** One stream is 40 total undo plus redo, not 40 in each. Before/after scenes can contain retained deleted IDs, which reserve duplicate allocation. Prepare concrete history target and locks first, and move stacks only on successful final staging. Selection-only changes do not invalidate the stream. No-op and failed branch must preserve redo.
16. **Replacement paths differ.** Sequence-only import does not replace the editor scene; Load step does. Failed/canceled/stale replacement preserves stable locks/history/selection after necessary gesture rollback. Successful already-live synchronous routes can stay Live under existing authority but always disarm aids; no replacement resets marked-view suppression. A blanket new concealment or a matching-ID selection carry-over violates the contract.
17. **A work budget must not remove validation.** Bounds passes have at most 12 items and small deterministic sorting, but input/output/locks/controller/shared geometry each legitimately validate. Require bounded passes, one planned candidate and one final stage, not an impossible single-validation promise. Record maximum-resource memory and same-runner handler/Hide measurements. No runtime timer or relaxed validator is a performance remedy.

## Constitution review

- User-control priority: every cancel/conceal and stale-result route retains authority; no edit or callback reveals or starts playback.
- Closed data/geometry: original validators, schema versions and envelopes remain; shared geometry and exact accepted payloads are preserved.
- Local minimal scope: session selection/history only, no groups, persistence, network, telemetry, packages or collection.
- Scientific restraint: coordinate tolerances, caps and performance measurements are engineering bounds, not medical safety or imagery/efficacy evidence.
- Accessible equivalents: semantic membership/anchor controls and exact non-drag routes are required alongside actual responsive inspection and separately reported external accessibility testing.
- Bounded cancellable work: 12 items, 40 total transactions, bounded ID reservation and no trails/bitmaps/new clock.
- Exact-source evidence: every changed-source result needs current hash/commands/versions; design calculations and historic runs cannot substitute.
- One register/reviewed integration: IF-050 remains the live register; verified Feature 012 main, independent review and exact-head CI precede integration. Release/hosting/research gates remain separate.

No constitution exception is requested for the functional design. Any proposed CI duration change is a separately documented coverage-estimation decision requiring independent review, not a validator/performance exception or relaxation of assertions.

## Remaining implementation choices and stop conditions

Freeze exact model result/error fields, raw-channel representation and keyed-control refresh strategy before concurrent writers rely on them. These choices may not alter the frozen observable semantics. A proposed CI duration estimate is not measured Feature 013 performance and cannot pass its performance gate. Stop for any unapproved capability change, unexplained measurement failure, unavailable exact baseline, or unresolved native/visual defect. Do not replace a failed acceptance case with a weaker one, confuse an unrun physical/AT procedure with a software pass, or claim implementation acceptance from this analysis.
